# Support Study Desk

> 공부 환경을 보조하는 올인원 스마트 학습 데스크 웹 서비스

## 📌 프로젝트 소개

집에서 공부할 때 모니터는 단순히 공간을 차지하는 경우가 많습니다.
본 프로젝트는 모니터를 학습 보조 도구로 활용할 수 있도록 다양한 기능을 제공하는 웹 기반 스마트 데스크 환경을 구현했습니다.

사용자는 하나의 화면에서 학습 시간 관리, 음악 재생, 일정 확인, 할 일 관리 등을 동시에 수행할 수 있습니다.

## ✨ 주요 기능

- ⏰ 포모도로 타이머
- ✅ 투두리스트
- 🎵 음악 플레이어
- 📅 캘린더 위젯
- 🌱 학습 시간 기반 성장 화분
- 🖼️ 감성 배경 및 애니메이션
- 🔐 Firebase 기반 로그인/회원가입
